# Planificación de proyecto_2

Este repositorio nace de la plantilla `npiobject/DesdeMovil`. Los documentos que
hay aquí por debajo de esta línea son **historia de la plantilla**, no de
`proyecto_2`: describen cómo se validó el flujo "PC arranca, móvil continúa"
(fases 0 a 3) y siguen nombrando al proyecto original. Se conservan como
referencia y no se reescriben.

| Documento | Qué es |
|---|---|
| `plantilla.md` | Cómo se usa la plantilla y qué hay que sustituir al clonarla. |
| `plan-flujo-movil.md`, `plan-flujo-movil-v2.md` | Plan y verificaciones del flujo. |
| `fase0-resultado.md` | Resultado de la fase 0 (Pages). |
| `fase3-fly.md` | Resultado de la fase 3 (backend en Fly.io). |
| `sesiones/` | Resúmenes de sesión, en orden cronológico. |

Todo documento nuevo de `proyecto_2` se escribe aquí y ya con el nombre de este
proyecto.
